# Madvertise

> Madvertise is a mobile advertising / monetization brand now operating within Azerion as the "BlueStack" (Improve Digital InApp) SDK and the mng-ads.com ad-serving platform. It provides mobile in-app ad monetization for publishers (banner, MREC, interstitial, native, rewarded video, App Open) across Android, iOS, Unity, React Native, Flutter and MAUI, plus programmatic ad-serving via an OpenRTB 2.5 bid-request API, a JSON ad-request API, VAST video, a Prebid Server adapter, and a token-authenticated reporting API family for sellers, buyers/DSPs and mediation.

## APIs
- [Ad Request API](https://developers.bluestack.app/adserving/ad-request-api-documentation): JSON ad-request endpoint at mobile.mng-ads.com (GET/POST, placement-based, unauthenticated).
- [OpenRTB Bid Request API](https://developers.bluestack.app/adserving/open-rtb-bid-request-api): OpenRTB 2.5 bid requests at mobile.mng-ads.com/bidrequest/{placement}; 200/204/400/500, errors in the x-bluestack-message header.
- [Seller Reporting API](https://developers.bluestack.app/reporting/seller-reporting-api): publisher revenue/delivery reporting; POST /auth-reporting then /seller-reporting, /status-reporting, /download-reporting.
- [Buyer Reporting API](https://developers.bluestack.app/reporting/buyer-reporting-api): advertiser-side reporting plus GET /campaigns.
- [DSP Reporting API](https://developers.bluestack.app/reporting/dsp-reporting-api): DSP view over /buyer-reporting.
- [Mediation Reporting API](https://developers.bluestack.app/reporting/mediation-reporting-api): POST /mediation-reporting with breakdowns and ad-network dimensions.
- [VAST](https://developers.bluestack.app/adserving/vast): VAST video ad markup.
- [Prebid Server Adapter](https://developers.bluestack.app/adserving/prebid-server-adapter): server-side header-bidding adapter.

Note: the reporting APIs are documented publicly but their base host is withheld — "accessed via the https://xxx.com domain (ask to your Azerion contact)".

## Agents
- [Improve Digital Publisher MCP Server](https://github.com/azerion/improvedigital-publisher-mcp-server): Azerion's first-party MCP server, six inventory/placement tools generated from a curated OpenAPI. It targets the sibling Improve Digital 360Yield publisher API (api.360yield.com), NOT the Madvertise ad-serving APIs.
- [Provider llms.txt](https://developers.bluestack.app/llms.txt): the BlueStack docs site publishes a real llms.txt index.
- No A2A agent card is served on any Madvertise, BlueStack or Azerion host.
